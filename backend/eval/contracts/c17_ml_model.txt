Acceptance criteria per milestone

Milestone 1: Data audit and labelling plan

Milestone 2: Baseline model
- Baseline classifier reaches at least 80% macro F1 on the held-out test set
- Training code is reproducible from a single command

Milestone 3: Production model and API
- Model reaches at least 88% macro F1 on the held-out test set
- Inference API responds in under 500 ms per image on the Client's server

Milestone 4: Documentation and handover
- Model card describing data, metrics and known limitations
- Handover session with the Client's engineering team
